Protocol Specification

Corda Intelligent Contract Architecture

1. The Defensible Outcomes Principle

Corda does not issue legal certifications and does not claim to prove absolute "zero telemetry." It evaluates whether public privacy marketing is defensibly consistent with public code:

  • DISCLOSURE_MATCH: Public code evidence is consistent with stated documentation.
  • DISCLOSURE_MISMATCH: Code evidence contradicts marketing (e.g. claims no tracking, but imports PostHog).
  • INSUFFICIENT_EVIDENCE: Evidence is missing, inconclusive, or inaccessible.

2. Non-Deterministic Consensus in GenVM

Standard smart contracts cannot execute external HTTP requests or LLM prompts deterministically. GenLayer solves this by isolating non-deterministic execution in gl.nondet and reconciling outputs across validators using comparative consensus:

result = gl.eq_principle.prompt_comparative(
  evaluate_claim,
  principle="The final verdict must be exactly one of: DISCLOSURE_MATCH, DISCLOSURE_MISMATCH, INSUFFICIENT_EVIDENCE."
)
